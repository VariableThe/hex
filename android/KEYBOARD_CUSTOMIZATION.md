# Android keyboard customization

The first milestone moves the existing number row to **Settings > Keyboard**.
It is on by default; explicitly saved on/off choices are still honored.

Use Yandex Keyboard as a usability reference, without copying assets or code.
- Layout: number row, height, spacing, long-press symbols, one-handed mode.
- Appearance: theme presets, key and suggestion colors, backgrounds, local
  preview and reset, with legible defaults.
- Controls: key feedback, shortcut and mic placement, and optional gestures.
- Before release, verify portrait, landscape, common layouts, number and
  password fields, symbol switching, and dictation cancel and commit.

This change requires no new permissions. Build and device tests are required
before APK delivery.
